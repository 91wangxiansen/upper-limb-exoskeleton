# 全上肢定姿态控制

双击本目录“启动上位机.bat”，打开 http://127.0.0.1:8765/ 。肩肘区显示组合上肢，页头“手指控制”直接切入原来的完整手部界面。

在组合场景中单击手部 CAD，或点击“手部详情”，在同一总界面切入完整手部控制台，页面地址保持不变。拖动手指仍只修改目标预览，移动超过6像素按拖动处理。完整控制台复用独立手部页面的四指控制、实时拖动、逐指抓握、速度设置、手势保存/预览/执行/删除、舵机ID搜索与改号、四指行程和阈值校准，以及最近30秒的负载/位置/速度/温度/电压曲线。页头“返回全上肢”回到组合场景。

两处页面共用同一个 Python 手部适配器和设备控制身份。首次使用在页面点击“连接手部”；切换页面不关闭驱动、不重发动作。配置与速度只在点击对应保存按钮后写入控制板，连接和查看页面仅读取状态。原来的独立臂部、手部归档目录保留。

1. 在肩肘控制区选择 CANable 串口，连接并按原流程核对准备状态。设置肩、肘目标角度，点击“执行肩肘目标”。设备按已有控制参数到达并保持目标。
2. 电脑 Wi-Fi 连接 Hand-Exo，切到手指控制，点击“连接手部”并启用手部驱动。可以用闭合百分比滑块或拖动模型调整四指目标，也可以拖动场景中的目标手指预览。
3. 点击“执行手指目标”下发四通道姿态。此步骤单独控制手部，肩肘继续执行原来的目标保持。可重新切回肩肘区设置下一组目标。

拖动模型或修改输入只改变透明预览。实色手臂由肩肘反馈驱动，实色手指由板上闭合量驱动。手部反馈超过2秒或离线时隐藏对应实际手部模型，避免旧数据充当实时状态。

手部装配复用原 CAD，挂接在前臂末端。为了适配原手臂示意模型，采用可视化缩放及安装方向，尚未进行实体安装位姿标定。四个模型通道沿用独立手部页面顺序，物理手指与舵机ID对应需在实机确认。

模型屈曲角沿用原手部耦合近似：闭合量0～100%对应近端0～约59.0°、远端0～约69.9°。板端使用整数闭合百分比及已有开闭端点生成编码位置。实际指节角度尚需机械标定和验证。

手部负载阈值、速度、行程及手臂限位、增益、转矩和补偿模型保持原配置。新增手部的质量尚未并入重力补偿。当前“停止肩肘电机”仍是原停止接口，手部“停止并保持”使用板端保持接口。

验证使用模拟设备，已通过先调肩肘再调四指的完整操作、角度换算、控制权冲突、刷新不重放、反馈过期，以及模型跟随前臂的测试。实机组合后的运动效果待验证。当前数据集按钮继续记录手臂数据。

## 参数输入范围

每个数字输入通过最小/最大属性和输入事件限制键入、粘贴及滑块值。悬停可查看范围；空白草稿无法提交，结束编辑时恢复上一次有效值。保存仍由原按钮明确触发。

| 参数 | 程序允许范围 |
| --- | --- |
| 肩肘目标角度 | 对应关节已保存的最小～最大角度 |
| 肩肘运动速度 | 0.02～已保存速度上限 rad/s |
| 肩肘转矩限制 | 0.1～已保存转矩上限 Nm |
| 最大速度 / 最大转矩设置 | 0.02～0.30 rad/s / 0.1～5 Nm |
| 关节 Kp / Kd | 0～20 / 0～5 |
| 校准最小/最大角度 | 程序没有固定绝对数值范围，最小值须严格小于最大值；目标运动仍受保存限位与协议检查约束 |
| 承托 Kp / Kd / Ki | 0.1～20 / 0.1～5 / 0.01～2 |
| 附加补偿上限 / 变化率 | 0.05～2.5 Nm / 0.01～0.4 Nm/s |
| 死区 / 最大学习误差 / 跟随误差变化率 | 0.05～1° / 1～15° / 0.02～0.15 rad/s，启用时死区还须小于到位容差 |
| 手指闭合量 | 0～100%，整数 |
| 舵机 ID | 1～20，四指 ID 互异，改号前后 ID 不同 |
| 张开/闭合位置 | 0～1023，两个位置至少相差20 |
| 手部负载阈值 / 速度 | 50～1000 / 20～500 编码步每秒，整数 |
| 手势名称 | 1～48 UTF-8字节 |

同页集成使用独立作用域复用原手部界面的结构、样式与控制逻辑。切回肩肘区时取消尚未发送的实时拖动，已接受的设备动作仍按板端策略运行。

## 肩肘曲线显示

网页合并去重后端重复返回的历史点，缓存最近60秒。数据不足60秒时按已收到的实际时间跨度展开横轴，左下角标注实际跨度，避免1200点后端缓存只占绘图区右侧。刷新页面后缓存从当前后端可提供的数据开始积累。

角度、速度、转矩和温度曲线采用100毫秒分段平均，再作时间常数0.35秒的指数低通，仅用于绘图，因此显示变化会略有延迟。绘图区设置最小纵轴跨度，避免保持时微小噪声被自动缩放放大。缺失点和超过1秒的反馈间隔分段绘制，过期反馈标记为“末次反馈”。控制、到位判断及数据集记录继续使用原始反馈。
